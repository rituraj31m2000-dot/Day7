# Phishing Email Analysis
**Veda Technology — Cyber Security Internship (Day 7, Task 7)**

## Objective
Analyze sample phishing emails to identify common suspicious indicators and build practical phishing-detection skills.

## Tools Used
- Sample phishing/safe emails
- Google Docs (for documentation)

## Approach
1. Collected a set of sample emails (mix of phishing and legitimate).
2. Reviewed each email against key red flags:
   - Sender address (spoofed/lookalike domains)
   - Embedded links (hover-check, shortened/mismatched URLs)
   - Urgency or threatening language
   - Unexpected or suspicious attachments
   - Generic greetings / poor grammar
   - Requests for sensitive info or credentials
3. Documented findings for each sample and flagged indicators found.
4. Compiled results into a reusable phishing indicator checklist.

## Deliverable: Phishing Indicator Checklist
- [ ] Sender email domain matches the claimed organization
- [ ] Links point to the actual expected domain (not shortened/masked)
- [ ] No urgent/threatening language pressuring immediate action
- [ ] No unexpected attachments (.exe, .zip, macro-enabled docs)
- [ ] Greeting is personalized, not generic ("Dear user")
- [ ] No request for passwords, OTPs, or payment details
- [ ] Grammar/spelling is professional and consistent

## Outcome
Successfully identified suspicious indicators across the sample set and produced a checklist that can be used to quickly triage suspected phishing emails.

## Interview Questions (Reference)
**Q: How do you identify phishing?**
A: By checking sender authenticity, link destinations, urgency cues, attachments, and grammar/formatting inconsistencies.

**Q: What is spear phishing?**
A: A targeted phishing attack aimed at a specific individual or organization, often using personalized details to appear more credible.

**Q: Why are shortened links risky?**
A: They hide the true destination URL, making it easy to disguise malicious sites as legitimate ones.
